# EDC Korea 2026 Personal Timetable

정적 HTML/CSS/JavaScript 웹앱입니다. `index.html`, `manifest.json`, `assets/`를 GitHub 저장소 최상위(root)에 업로드하고 Vercel에서 Framework Preset을 `Other`로 배포하세요. 별도 빌드 명령은 필요하지 않습니다.

## 기능
- 10월 3일/4일 날짜 전환, 스테이지 필터, DJ 검색
- 표 형태의 타임테이블과 클릭 선택
- 선택한 공연을 페이지 하단의 나만의 라인업 표에 표시하고 선택 해제
- 별표 즐겨찾기 및 브라우저 저장
- DJ 상세 정보/사진 자동 조회, YouTube 및 Spotify 검색
- 즐겨찾기 공연 시간 중복 확인, 개인 DJ 랭킹, 배경화면 생성
- 공식 타임테이블 이미지 확인

DJ 프로필 사진과 소개는 Wikipedia 공개 API를 통해 조회하며, 문서/이미지 제공 여부와 네트워크 환경에 따라 일부는 이니셜로 표시될 수 있습니다. 팬메이드 비공식 앱이므로 공연 정보는 공식 공지와 대조해 확인하세요.
