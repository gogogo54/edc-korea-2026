# EDC KOREA 2026 · 내 타임테이블

사용자가 제공한 EDC Korea 2026 10월 3일/4일 타임테이블 이미지와 지정 웹사이트의 기능 설명을 참고해 만든 개인용 팬메이드 정적 웹앱입니다.

## 포함 기능
- 10/3·10/4 날짜 전환
- 스테이지 필터 / DJ 검색
- 내 타임테이블(⭐) 저장
- 공연 상세 + YouTube/Spotify 검색
- 선택 공연 시간 겹침 계산
- 내 DJ 랭킹(이 기기 저장 기준)
- 스마트폰 배경화면 이미지 생성/저장
- 공식 타임테이블 이미지 보기
- 모바일 최적화 / PWA manifest
